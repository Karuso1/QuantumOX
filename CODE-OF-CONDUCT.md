# Code of Conduct — QuantumOX

## Purpose

The purpose of this Code of Conduct is to ensure that the QuantumOX project remains a welcoming, inclusive, and respectful environment for all contributors and users.

All participants are expected to contribute positively and behave professionally in all project spaces, including discussions, issues, pull requests, and community communications.

---

## Our Standards

### Expected Behavior

* Use respectful and inclusive language.
* Be welcoming and supportive of diverse perspectives.
* Give and gracefully accept constructive feedback.
* Focus on collaboration and shared learning.
* Respect differing opinions, experiences, and skill levels.

### Unacceptable Behavior

* Harassment, discrimination, or personal attacks.
* Insults, derogatory comments, or trolling.
* Public or private harassment of any kind.
* Publishing private information without consent.
* Any conduct that disrupts the collaborative environment.

---

## Enforcement

Project maintainers are responsible for enforcing this Code of Conduct. Inappropriate behavior may result in:

* A warning from maintainers.
* Temporary or permanent ban from the repository.
* Reporting to GitHub if severe violations occur.

All decisions by maintainers will aim to be fair and transparent.

---

## Reporting

If you observe or experience behavior that violates this Code of Conduct, please report it by opening a private issue or contacting the project maintainer directly.

Reports will be handled confidentially and reviewed promptly.
